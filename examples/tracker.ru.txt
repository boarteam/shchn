Так, давайте накидаем модель данных для таск-трекера. Основная сущность — Project. У проекта есть name, description и owner, owner — это User.

У User есть email, name и avatar url. Пользователь может состоять в нескольких командах, то есть у юзера есть список Team, а у Team есть название и список members.

Дальше Task. Каждая задача принадлежит проекту, у неё есть title, description, status и priority. У задачи есть assignee, это тоже User, и reporter, тоже User.

Ещё нужны комментарии. Comment относится к задаче, у него есть author, text и дата создания.

Хотя нет, priority давайте уберём, будем вместо этого использовать labels. Label — это отдельная сущность, у неё name и color, и у задачи может быть много лейблов.

И ещё, давайте переименуем Team в Workspace, так понятнее. А, и у задачи нужен due date.
